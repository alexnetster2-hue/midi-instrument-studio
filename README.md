# MIDI 악기 스튜디오 (MIDI Instrument Studio)

브라우저에서 바로 쓰는 MIDI 재생·악기 스튜디오. 서버 없이 정적 웹페이지 하나로 동작합니다. `index.html`을 브라우저로 열면 됩니다.

## 시작하기

1. **템플릿 고르기** — 재즈 스윙 / 락 / 차차차 / 라틴팝·보사노바 / 시티팝 / 클래식풍, 8마디·4트랙 장르 템플릿 중 선택 (직접 가진 MIDI 파일을 불러올 수도 있습니다)
2. **폰트 고르기** — SF2 사운드폰트를 보관함에 추가하고 트랙에 적용
3. **재생 버튼 누르기** — 재생 / 일시정지 / 정지, BPM 조절, 타임라인 탐색

## 주요 기능

- **SF2 재생**: SF2 사운드폰트(존·벨로시티 범위·루프·엔벨로프 지원)를 불러와 실제 녹음 악기 소리로 재생
- **표현영역 교체**: 악기를 소리 성격이 비슷한 그룹(건반 / 기타 / 현악 / 관악 / 베이스 / 드럼 등)으로 묶어, 같은 그룹 안에서 다른 악기로 바꿔 들으며 탐색. 다른 그룹으로 바꾸는 큰 변화는 별도 영역으로 구분
- **추천·세트**: 트랙 역할(드럼 / 베이스 / 패드 / 멜로디)에 맞는 악기 추천 칩, SF2별 세트 추천
- **작곡 도구**: 12개 장조 전조, 코드 진행 프리셋 5종(ii–V–I, I–V–vi–IV, I–vi–ii–V, 12마디 블루스, vi–IV–I–V, 템플릿 전용)
- **노트 편집**: 피아노 롤에서 노트 추가·이동·길이 조절·세기 조절·삭제, 되돌리기/다시 실행
- **폰트 비교**: 같은 템플릿 구간을 불러온 SF2별로 렌더링해 들어보고 비교 (SF2 2개 이상 필요)
- **WAV 악기**: WAV 파일을 SF2 변환 없이 바로 악기로 등록 (기준 음 기본 C4, 피치시프트 연주, 루프 설정)
- **내보내기**: MIDI / WAV / MP3 / 영상 내보내기
- **모바일 대응**: 1옥타브 건반 + 옥타브 이동 버튼, 트랙 탭

## SF2에 대해

- 이 저장소에는 SF2 파일이 포함되어 있지 않습니다 (라이선스·용량 이유).
- 직접 구한 SF2 파일을 앱의 보관함에 추가해서 쓰세요. FluidR3, GeneralUser-GS, Arachno, TimGM6mb, Salamander C5 피아노(SalC5Light2) 같은 무료 폰트와 함께 쓸 수 있습니다.
- SF2와 WAV 악기는 세션 전용 보관입니다. 탭을 닫으면 사라지니 다시 불러와야 합니다. 파일 상한은 256MB입니다.
